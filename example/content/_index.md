Monospace fonts are dear to many of us. Some find them more readable,
consistent, and beautiful than their proportional alternatives.
[The Monospace Web](https://owickstrom.github.io/the-monospace-web/) by Oskar
Wickström is a design exploration built on that idea: a page where every element
is aligned to a grid of character cells.

This site is that design, ported to a Hugo theme. Everything you see here —
the masthead table, the post index below, the code blocks — sits on a grid of
one character wide by one line tall. Tick **Debug mode** above to see it, and to
have anything sitting off the grid highlighted in red.

See the [component reference](docs/) for the markup, and
[Configuration](docs/configuration/) for the site params.
